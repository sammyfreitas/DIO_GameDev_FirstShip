SOBRE O PROJETO

Do exercício de bootcamp a uma experiência mais completa.

Este projeto nasceu no curso “Construindo o seu primeiro jogo de naves”, do Bootcamp JavaScript Game Developer da Digital Innovation One. A versão atual preserva a mecânica original em HTML, CSS, JavaScript e jQuery, mas reorganiza a experiência com uma interface responsiva e recursos novos.

Comandos simples. Pontuação estratégica.

Use ↑ e ↓ para mover o helicóptero e D para disparar. Cada disparo que sai da tela sem atingir um inimigo conta como erro.

Sem limite: resgate 5 civis para concluir a missão. O bônus final valoriza rapidez e precisão. 90 segundos: faça a maior pontuação antes do tempo acabar.
